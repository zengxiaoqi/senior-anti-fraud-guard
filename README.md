# 「长者防诈守护」系统完整产品与技术解决方案

---

## 1. 项目背景与设计哲学

### 1.1 核心痛点
1. **老人当局者迷**：老年人在遭受电信诈骗、保健品线下洗脑、养老投资骗局时，处于高度被洗脑状态，自身缺乏识别能力，不会主动触发求助或警报。
2. **传统监控侵权且不可行**：静默窃听、后台隐蔽录音、强行抓取微信/支付宝数据存在严重法律风险（违反《个人信息保护法》、《刑法》第283条/285条），且会被 iOS/Android 系统及安全软件直接封杀。
3. **事后维权举证难**：老人被骗后受限于记忆模糊、证据被抹除等原因，无法提供有效的收款账号、通讯记录与现场轨迹，导致警方难以立案和冻结资金。

### 1.2 产品核心设计原则
* **无感感知**：不依赖老人主动操作，通过**行为特征分析算法**自动识别异常。
* **合法合规**：基于**透明授权 + 行为指标监测 + 系统公开 API**，绝不进行隐蔽偷录或侵入式窃听。
* **实时干预**：构建**“高危行为感知 $\rightarrow$ 子女端强提醒 $\rightarrow$ 远程亲情打断”**闭环。
* **证据留存**：自动聚合**资金流向链 + 通讯链 + 时空轨迹链 + 告知式场景录音**，形成一键报案证据包。

## 3. 核心功能模块设计

### 3.1 异常行为无感感知模块（老人端）

#### (1) 异常通话行为监测
* **技术实现**：基于 Android `TelephonyManager` / `CallScreeningService` 监听通话状态。
* **判定逻辑**：
  * 通话号码不在老人通讯录中；
  * 单次通话时长超过 **15 分钟**；
  * 或 2 小时内与同一陌生号码频次 $\ge 3$ 次。
* **执行动作**：向云端上报风险事件 `EVENT_SUSPICIOUS_CALL`。

#### (2) 敏感地点停留感知
* **技术实现**：基于高精度 GPS / Wi-Fi 探针 / 基站定位，结合高德/百度地图 API 的 POI 分类。
* **判定逻辑**：
  * 识别离家状态下在“保健品体验店”、“养生讲座酒店”、“农信社/银行”附近 50 米内停留超过 **40 分钟**。
* **执行动作**：向云端上报风险事件 `EVENT_SENSITIVE_LOCATION_STAY`。

#### (3) 异常支付通知捕获
* **技术实现**：基于 Android `NotificationListenerService`（通知栏监听服务）。
* **判定逻辑**：
  * 解析系统通知中的银行卡扣款短信、微信/支付宝支付成功通知；
  * 提取关键字段：金额、收款方名称；
  * 匹配规则：单笔金额 $> 500$ 元，或 1 小时内连笔支付。
* **执行动作**：同步交易快照 `EVENT_PAYMENT_DETECTED` 至子女端。

#### (4) AI 图文防诈助手
* **技术实现**：集成多模态大语言模型（Vision LLM）与 OCR 技术。
* **使用场景**：老人拍照保健品宣传单、假收据、可疑短信截图，AI 自动识别洗脑话术、虚假宣传与提现陷阱，给出红黄绿风险评级。

---

### 3.2 亲情干预与强打断模块（子女端）

当云端判定风险等级提升为 **【高危（Red Alert）】** 时：

1. **子女端强提醒推送**：子女手机收到高优先级音效推送（穿透静音），显示具体风险来源（如：*“母亲正与陌生号码通话 18 分钟”*）。
2. **远程亲情强响/语音打断**：
   * 子女可在 App 点击“远程拉起弹窗”；
   * 老人手机屏幕被红色安全提示覆屏，播放子女预录防骗语音：*“爸！千万别给陌生人转账，这是诈骗！”*，强制打断洗脑状态。
3. **资金风控联动**：
   * 联合微信/支付宝“亲情卡”与银行卡日限额，大额转账需子女手机协同授权。

---

### 3.3 自动化维权与证据链聚合模块

当不幸发生受骗事件时，系统一键生成具备法律效力的《反诈报案维权证据包》：

```
《反诈报案维权证据包》组成结构：
├── 1. 资金流向链
│   ├── 交易时间戳 / 扣款金额
│   ├── 收款方商户全称 / 商户号 / 银行卡号
│   └── 交易单据电子快照
├── 2. 通讯与话术链
│   ├── 诈骗电话号码 / 归属地 / 通话时长记录
│   └── 涉诈短信及诱导链接解析
├── 3. 空间轨迹链
│   ├── 老人停留地点 GPS 经纬度及地址
│   └── 现场停留起始时间与时长证明
└── 4. 场景合规存证
    └── 高危状态下经过公开告知录制的防诈环境音频片段
```

## 4. 法律合规与隐私安全保障

| 维度 | 合规要求 | 本方案落地方案 |
| :--- | :--- | :--- |
| **知情授权** | 严禁隐蔽偷窥 | 老人端首次安装时，必须由子女与老人共同完成透明授权，主界面显著展示“防诈守护服务运行中”。 |
| **音频录制** | 严禁后台窃听 | 不进行全局后台窃听。仅在系统判定高危状态时，界面明确弹窗告知“已开启亲情防诈安全存证”后方可录音。 |
| **数据传输** | 防止隐私泄露 | 采用 TLS 1.3 + AES-256 端到端加密传输，敏感支付信息与轨迹仅对绑定亲情账号可见。 |
| **应用市场** | 符合 Google/Apple/国内厂商规范 | 不使用隐藏图标、注入无障碍漏洞等木马手段，符合合法亲情守护（Family Care）应用规范。 |

## 5. 项目落地技术栈推荐

* **老人端 App**：Android Native (Kotlin / Jetpack) - 方便深度调用后台定位与通知栏监听服务。
* **子女端 App**：Flutter / React Native - 跨平台（iOS & Android），方便快捷开发。
* **后端服务**：Node.js / Go + PostgreSQL + Redis - 高并发 WebSocket 实时状态同步。
* **AI 风险引擎**：集成 OpenAI / DeepSeek / Gemini Vision 多模态模型进行欺诈文本及图像解析。

---

## 6. 结论

本方案彻底解决了传统思路中“违规窃听”和“老人无法自觉”的两大悖论。通过**“合规行为感知 + 子女远程干预 + 自动化证据链”**三位一体的闭环设计，既满足法律合规与上线要求，又能真正为老年人构建起一道坚不可摧的防诈安全屏障。
